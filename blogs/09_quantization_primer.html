A Primer to Understanding Quantization for LLMs

May 22, 2026 • 10 min read

The more and more LLMs get better, they also seem to be getting bigger. The frontier models have over 1 trillion parameters. It's also cool when all you have to do is invoke an api and generate the response. What if i wanted to host this model myself? What would i need to do. First step would be to load the weights into memory. For context, a 70B Llama in fp32 would need ~ 32/8 * 70 = 280 GB. Oh, 280GB for a 70B model? Forget about 1T models then. Just kidding. This is where quantization is super crucial. In plain terms, quantization is a technique by which i can make LLMs N times smaller and faster just sacrificing a fraction of performance. Pretty cool yes?

But before talking about how quantization works, you really need to lock in the concept of how numbers are stored in memory. We will focus mostly on the floating point formats like half(fp16), bfloat16, and int8. So this post is really about building the mental model for those formats first.
